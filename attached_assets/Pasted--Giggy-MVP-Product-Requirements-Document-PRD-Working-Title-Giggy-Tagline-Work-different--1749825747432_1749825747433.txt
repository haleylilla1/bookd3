📱 Giggy — MVP Product Requirements Document (PRD)
🎯 Working Title: Giggy
Tagline: Work different.

1. 🧠 What is the App?
Giggy is a lightweight financial and career tracking app designed specifically for live-service gig workers—brand ambassadors, caterers, bartenders, and more. Unlike generic budgeting tools or freelance marketplaces, Giggy focuses on tracking gigs, logging pay, prepping taxes, and visualizing progress—all in under a minute per entry.

2. 🧍‍♀️ Who is it for?
Target Users:
Brand ambassadors

Freelance event staff

Bartenders and caterers

Touring promo reps

Freelance hospitality professionals

User Pain Points Solved:
Inconsistent or late payments

Losing track of unpaid gigs or receipts

Needing resume updates for new jobs

Uncertainty around self-employment taxes

No clear overview of monthly gig income

3. 🧩 Core Features (Screens)
📅 SCREEN 1: Calendar View
Purpose: Let users visualize gigs at a glance.

Key UI:

Monthly grid

Colored dots:

✅ Green = Completed

🟣 Purple = Upcoming

🟠 Orange = Pending Payment

FAB: “+ Add Gig”

📝 SCREEN 2: New Gig Entry
Purpose: Rapid gig tracking form.

Fields:

Type of gig (dropdown + add new)

Client name (autocomplete)

Date

Expected vs. Paid amount

Payment method

Expenses (toggle + predefined categories)

Duties (for resume)

Suggested tax % (default 23%)

Mileage (multi-stop)

Long Distance (toggle + flight, rideshare fields)

Notes

Save Button: Minimal friction, < 1 min

📊 SCREEN 3: Dashboard
Purpose: Visual overview of earnings + insights.

Widgets:

Weekly / Monthly / Annual income

Top clients leaderboard

Gigs completed

Tax estimate

Goal progress ($2500 / $3000)

📄 SCREEN 4: Resume Builder
Purpose: Auto-build a resume from gig data.

Features:

Resume preview section

Toggle to include/exclude gigs

AI-generated suggestions (e.g. skill highlights)

Export to PDF

Upload existing resume for enhancement

🎯 SCREEN 5: Gig-to-Goal Tracker
Purpose: Help users allocate gig income with intention.

Interaction:

Show recent gig earnings

Drag/drop or assign $$ to:

Savings

Rent

Gear

Unassigned → Suggest a category

Visual progress bars per goal

4. 🧱 Frameworks & Tools
🧰 Front-End:
React Native (Expo) – fast cross-platform deployment

Tailwind (via NativeWind) – sleek mobile UI styling

Recoil or Redux – for state management (e.g. gig entries)

🔧 Back-End:
Firebase / Supabase – lightweight backend + auth

Google Cloud Functions / Node.js – handle PDF export, mileage calcs

Plaid or MX (optional) – bank sync for confirming gig payments

📄 PDF Resume Export:
react-native-html-to-pdf or server-side PDF generator (Node + Puppeteer)

✈️ Mileage Tracking:
Simple calculation via Google Maps API or manual entry to start

5. 🧠 Patterns & UX Principles
Product Patterns:
Calendar-first workflow (visual memory trigger)

Auto-fill + autocomplete for speed

Chunking by context (calendar, gigs, money, resume, goals)

Low-effort input → High-value output (e.g. resume, tax prep)

UX Goals:
Under 60 seconds per gig log

Only 1-2 taps needed to check financial progress

No jargon. Use event lingo: “Shift,” “Client,” “Setup,” “Per Diem”

6. 💡 Ways to Make It Invaluable to Your Audience
Feature	Value to User
Calendar + Gig Logging	Replaces manual notes and reminders
Auto Tax Estimate	Avoids surprise tax bills
Mileage + Expense Logging	Tracks write-offs without needing an accountant
Goal-Based Allocation	Turns scattered income into a strategy
Resume Export	Helps users land more gigs
